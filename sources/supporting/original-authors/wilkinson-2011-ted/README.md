## Files and provenance

- [captions.en.json3](captions.en.json3): the English subtitle response downloaded from the linked YouTube video, preserved byte for byte. The track was listed under ordinary English subtitles, not automatic captions. This identifies the published track, not a separate audio accuracy assessment.
- [transcript.en.csv](transcript.en.csv): all 385 text-bearing cues, in their original order. Speech captions start at 00:00:15.260 and the final applause cue ends at 00:16:48.260. Silence and the opening sequence have no added text.
- [source.json](source.json): retrieval metadata, source URLs, attribution, licence and SHA-256 checksums of the raw subtitle response and CSV.

The CSV columns are cue_id, start_ms, duration_ms, end_ms, start_time, end_time and text. Times are offsets from the start of the linked YouTube video, not TED.com player offsets. A row is a subtitle cue, not necessarily a complete sentence. CSV quoting preserves embedded line breaks. Caption wording, punctuation, spelling and stage directions have not been edited, translated, corrected or deduplicated. The conversion joins each cue's JSON text segments in source order and adds only cue numbers and equivalent time representations.

To regenerate the CSV without network access, run from the repository root:

```sh
make -f make/original-access.mk
```

The standalone Make target works before the planned shared scaffold is implemented and is listed in REPLAY_TARGETS for later integration.

The caption track was retrieved on 19 October 2026 in Europe/Helsinki; source.json records the UTC retrieval timestamp. Only subtitles and video metadata were obtained, not the video or audio. Neither the raw response nor the CSV has been independently checked word by word against the audio.
