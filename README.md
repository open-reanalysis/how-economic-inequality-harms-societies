# How Economic Inequality Harms Societies: an Open Reanalysis

A transparent, reproducible examination of the macro-comparative analyses in Richard Wilkinson and Kate Pickett's *The Spirit Level*. The project does not set out to prove or disprove the authors. It produces three separate results and keeps them separate in every table, figure and sentence.

> **Status: pre-release.** Nothing has been analysed yet. The analysis lock (see [Declared before examined](#declared-before-examined)) has not been committed. No result is reported until it has.

## The three results

| Result | Question | Label used in outputs |
|---|---|---|
| **A. Original reproduction** | Do the data Wilkinson and Pickett released reproduce the correlations and the composite Health and Social Problems Index they reported? If the files are unavailable, the same question is answered as a reconstruction from documented secondary material. | `ORIGINAL` or `RECONSTRUCTION` |
| **B. Current replication** | Using current data, a pre-specified country sample and a pre-specified source hierarchy, are comparable cross-sectional correlations present today? | `CURRENT` |
| **C. Sensitivity** | Do A or B change under alternatives that a named critic has actually raised? | `SENSITIVITY` + critic ID |

A fourth section, **interpretation**, records what the analysis does and does not establish. The project does not estimate a causal effect of inequality. Fixed-effects and covariate models are sensitivity analyses only.

## Vocabulary

| Term | Meaning here |
|---|---|
| Reported correlation | What the authors computed |
| Robustness | Whether that correlation survives reasonable alternative choices |
| Mechanism | An explanation of why a correlation might exist |
| Causal claim | Changing inequality would change outcomes |
| Policy prediction | A specific intervention would produce a specific result |

"Correlation does not establish causation" applies only to causal claims and policy predictions. It is never recorded as a criticism of whether a reported correlation is accurate.

Words such as *debunk*, *toxic*, *cherry-picking*, *proves* and *disproves* appear only inside quotations attributed to an identified source. Findings use neutral phrasing: "was correlated with", "the estimate was sensitive to", "the result changed when", "data were not sufficiently comparable to assess".

Causal readings, mechanisms and policy predictions are reported only when explicitly advanced by Wilkinson and Pickett or another cited source, and each is labelled as an author claim, critic claim or project result.

## Principles

### Provenance before analysis
Every file is stored exactly as downloaded, with URL, UTC timestamp, SHA-256 checksum and licence terms. Raw folders are never overwritten.

### Declared before examined
Country inclusion rules, inequality measure, source hierarchy, year alignment and index construction are written down and committed in an **analysis lock** before any outcome is correlated with inequality. The lock's commit hash is stamped on every report. Sources are never chosen by the strength of the correlation they produce.

### Source hierarchy, not fixed sources
For each indicator the lock names a preferred source, permitted fallbacks, minimum comparability conditions and the circumstances that justify a fallback. A fallback is recorded before the outcome is joined to inequality.

### Versioned "current" data
"Current" means the version of each source retrieved during the declared acquisition window, pinned by retrieval time, release or version identifier, query parameters and checksum. A later rerun against revised live data is a new acquisition, not the same analysis.

### No silent choices
Where the original method is undocumented, alternatives are implemented side by side and labelled. The primary analysis uses no imputation. Outliers are never dropped without reporting both retained and excluded results.

### Attributed criticism only
A criticism enters the executable register only with four fields: critic name, exact source title, publication year, and a stable DOI, PMID, PMCID or URL. Generic critiques that no named author made are excluded.

### Legal access only
Paywalls and access controls are not bypassed. A restricted item gets a bibliographic record and a note that it was not downloaded.

### Everything from code
Tables, figures, manifests, the data dictionary and the report are generated by scripts. The final build is an offline replay from a fresh environment using only previously acquired, checksummed local assets. Data acquisition is a separate, network-enabled command.

## Facts that must be verified before use

Each item is logged in `docs/discrepancy_log.md` with its source once checked.

- [ ] Original country list and per-outcome sample sizes. No secondary-source count (21, 22 or 23) is used as a target.
- [ ] Original inequality measure and reference year.
- [ ] Original direction coding of each index component, recovered from original materials. The 2024 appendix's coding is recorded separately as update documentation.
- [ ] Original handling of missing index components.
- [ ] Details of the 2024 update, extracted from the [technical appendix](https://eprints.whiterose.ac.uk/id/eprint/215026/7/Technical_Appendix_20_07.pdf) (sample, inequality year, Gini versus 80:20).
- [ ] Current availability and terms of the Equality Trust data files. This is the first task, because Result A depends on it.


## Out of scope

- Estimating a causal effect of inequality.
- Analysing U.S.-state material in the first release. If the original package contains it, only its existence, file names and provenance are recorded.

## Definition of done

1. Original data are preserved, checksummed and analysed, or their absence is documented and the reconstruction path is labelled.
2. Every required primary dataset is validated, or a predeclared fallback or labelled omission applies. Access failure never permits silent substitution.
3. Original findings are reproduced, or every non-reproduction is explained in the discrepancy log.
4. The analysis lock is committed before outcome analysis.
5. Every controversy in the report is attributed to an identifiable source.
6. Test data for each stated criticism are saved.
7. Every result states its dataset versions, country sample, year ranges, source IDs and lock commit hash.
8. All scripts run end to end from a clean environment.
